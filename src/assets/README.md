Photographs representing Muthu Kumar M for the personal portfolio.

The React portfolio uses the WebP copies; `story.html` keeps the JPEGs. `hardik-camera-chip.webp` is the exact region the Approach statement's inline chip shows.

`hardik-bench-subject.webp` (2244x2804, quality 90, lossless alpha) is the front layer for the landing page cover, where the name passes behind Muthu Kumar M's head. It sits exactly over the photograph beneath.

`hardik-bench-scene.webp` (2244x2804, quality 82) is the landing cover photograph. Muthu Kumar M, the bench slats and everything below the seat (legs, cobblestones) are the photograph's own pixels. The background wall provides a clean aesthetic setting with subtle grain and lighting.

`hardik-bench-wall.png` (561x701, alpha mask, 28 KB) masks the wall in the cover photograph, including gaps between bench slats. The long-exposure cover uses it, registered to the photograph's crop, as a CSS mask for the static veil and inside the star-trail canvas.
